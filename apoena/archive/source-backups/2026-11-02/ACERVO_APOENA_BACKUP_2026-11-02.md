## Limites desta cópia GitHub

Este commit preserva o inventário e o registro de proveniência. Os conectores GitHub usados nesta operação aceitam criação de arquivos UTF-8, mas não fazem upload binário direto de PDF/DOCX. Portanto, os originais binários estão no pacote ZIP local, e não dentro deste repositório por este commit. As extrações textuais e seus hashes estão no pacote ZIP.
