# Modelo Padrão de Registro de Conhecimento Apoena

Use este modelo para registrar descobertas, decisões, correções e aprendizados relevantes no ecossistema Apoena. Preencha os campos aplicáveis; não transforme hipóteses em fatos.

## Registro preenchível

- **Título:** [Nome do conhecimento]
- **Data:** [DD/MM/AAAA]
- **Projeto:** [Nome do projeto]
- **Categoria:** [Personagem / História / Jogo / Software / Decisão / Correção / Outro]
- **Status:** [Confirmado / Em análise / Hipótese / Sugestão / Pendente]
- **Descrição:** [O que foi descoberto, desenvolvido ou decidido]
- **Decisões e justificativas:** [O que foi aprovado e por quê]
- **Arquivos envolvidos:** [Caminhos e links]
- **Problemas encontrados:** [Descrição]
- **Soluções:** [Aplicadas ou propostas; identifique qual]
- **Pendências:** [O que falta]
- **Próximos passos:** [Ações futuras]
- **Fontes e evidências:** [Documentos, links, testes ou logs]
- **Responsável:** [Pessoa ou IA]
- **Autorização para alteração:** [Concedida / Aguardando / Não necessária]
- **Registro no repositório:** [Publicado / Não publicado / Não verificado]

## Procedimento de preservação

1. Verifique se o conhecimento já existe e compare documentos relacionados.
2. Registre a origem e diferencie fatos, hipóteses, sugestões e pendências.
3. Preserve o histórico; não apague ou substitua registros anteriores sem autorização.
4. Antes de alterar repositórios, obtenha autorização explícita e faça backup quando possível.
5. Após publicar, confira o arquivo e informe o caminho, commit e resultado verificado.
6. Se não houver acesso, entregue o registro pronto para inclusão e declare que não foi publicado.

**Regra fundamental:** nunca afirme que um registro foi salvo ou verificado sem confirmar a operação.
